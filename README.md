# 掌中酒馆 APK 更新

本仓库公开提供 Android ARM64 安装包、版本清单、SHA-256 校验值和更新说明；开发仓库保持私有。

- [下载最新正式版](https://github.com/ruoruo43/pocket-tavern-updates/releases/latest)
- 固定更新源：`https://github.com/ruoruo43/pocket-tavern-updates/releases/latest/download/update.json`
- 应用内入口：聊天右上角「设置 → 更新中心」。
- 普通扩展：在「设置 → 插件与扩展市场」安装、检查和更新。

直接覆盖安装，不需要卸载原版掌中酒馆。更新会校验包名、递增版本和签名；下载更新还会验证 SHA-256，最终安装由 Android 系统请你确认。请先发送或保存未发送的草稿。

SillyTavern 核心、本机适配与固定预装扩展经适配和验证后随新版 APK 发布。带有用户修改、分支切换或主动删除的扩展保持原样，避免覆盖自定义版本。

应用不附带 AI 账号、API 密钥、私人角色卡或聊天资料。测试范围、文件哈希以每个 Release 的说明为准。

SillyTavern、酒馆助手及提示词模板保留各自许可证。APK 内 `assets/sillytavern.zip` 保留运行的酒馆及修改源码，`assets/bundled-extensions.zip` 保留预装扩展源码和许可证。开发归档不会上传到本公开仓库。
